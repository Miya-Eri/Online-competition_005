# 🌕 เว็บแอปพลิเคชันประกวดลอยกระทงออนไลน์ 3D (Loy Krathong 3D Voting App)

เว็บแอปพลิเคชันประกวดและโหวตกระทงออนไลน์แบบอินเตอร์แอคทีฟ 3 มิติ (3D Interactive Web App) พัฒนาด้วย **Three.js** และ **React + Vite** รองรับการใช้งานทั้งบนคอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน (Responsive Web Design)

---

## 🌟 ฟีเจอร์เด่น (Key Features)

1. **ฉาก 3 มิติยามค่ำคืน (Three.js 3D Night Scene):**
   - **แม่น้ำ (River Simulation):** ผิวน้ำสะท้อนแสงไฟและแสงจันทร์ พร้อมระลอกคลื่นสมจริง
   - **ดวงจันทร์เต็มดวง (Full Moon):** พระจันทร์ส่องแสงนวลลงสู่แม่น้ำและดวงดาวระยิบระยับ
   - **สถาปัตยกรรมไทย:** วัดไทย, พระเจดีย์ทองอร่าม, และเรือนไทยโบราณริมน้ำ
   - **ผู้คนและบรรยากาศงาน:** โมเดลคน 20 คนเดินชมงานริมตลิ่ง พร้อมโคมไฟประดับสองฝั่งแม่น้ำ
   - **กระทงในแม่น้ำ:** กระทงเริ่มต้น 20 ใบหลากสีสัน ลอยตามกระแสน้ำพร้อมเปลวเทียนเรืองแสง

2. **ป้ายชื่อและรูปถ่ายลอยเหนือกระทง (Floating Name & Photo 3D Badges):**
   - แสดงรูปถ่ายเซลฟี่จริงของผู้เข้าประกวด
   - แสดงชื่อผู้เข้าประกวด และจำนวนคะแนนโหวตสดแบบเรียลไทม์
   - หันตามมุมกล้องอัตโนมัติ (Billboard 3D Sprite) มองเห็นชัดเจนจากทุกมุมมอง

3. **การควบคุมมุมกล้อง (Camera Controls):**
   - หมุนฉาก (Rotate) 360 องศา
   - ซูมเข้า - ซูมออก (Zoom In / Out) สะดวกทั้งเมาส์และ Touch Gesture บนมือถือ

4. **ระบบถ่ายรูปเซลฟี่ & ส่งกระทงเข้าประกวด:**
   - ถ่ายรูปเซลฟี่ผ่านกล้องหน้าของอุปกรณ์ หรือเลือกอัปโหลดไฟล์ภาพ
   - ป้อนชื่อผู้ส่ง และพิมพ์คำอธิษฐานต่อพระแม่คงคา
   - เลือกสไตล์กระทง 3 มิติ (กระทงบัว, กระทงใบตอง, กระทงชาววัง, กระทงดอกไม้, กระทงกะลา)
   - สร้างและปล่อยกระทงลงแม่น้ำทันที พร้อมมุมกล้องบินไปโฟกัส

5. **ระบบแตะกระทงและลงคะแนนโหวต (Interactive Raycasting & Voting):**
   - แตะที่ตัวกระทงหรือป้ายชื่อเพื่อเปิด Popup ดูรูปขนาดใหญ่และคำอธิษฐาน
   - กดโหวตให้กระทง พร้อมเอฟเฟกต์พลุฉลอง (Confetti)
   - กติกาความโปร่งใส: **1 บัญชีผู้ใช้ โหวตได้วันละ 1 ครั้ง**

6. **ระบบสมาชิก (Authentication):**
   - รองรับ Google Sign-In และ เบอร์โทรศัพท์ (SMS OTP)

7. **ตารางจัดอันดับ Top 10 (Leaderboard):**
   - ดู 10 อันดับคะแนนสูงสุด พร้อมปุ่ม "บินไปดู" เพื่อให้กล้อง 3D ซูมพาไปชมกระทงนั้น

8. **ระบบหลังบ้าน (Admin Dashboard):**
   - คัดกรองและตรวจสอบรูปถ่าย/คำอธิษฐาน (Approve / Reject)

---

## 🚀 วิธีการติดตั้งและรันในเครื่อง (Getting Started)

```bash
# ติดตั้ง dependencies
npm install

# รัน Development Server
npm run dev

# บิลด์สำหรับ Production
npm run build
```
